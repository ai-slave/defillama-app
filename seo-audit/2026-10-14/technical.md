# Technical SEO audit — defillama.com — 2026-10-14

Angle: technical. No application code was changed.

## Method

**Search Console.** Attached export for `sc-domain:defillama.com`, search type web, `dataState: all`, day `2026-10-12` (the newest day in that pull with a full row set). Property totals that day: 5,562 clicks, 96,048 impressions, 5.79% CTR, average position 6.11. `missed@3%` = `max(0, 0.03 × impressions − clicks)`. Page impressions are not additive to the property total.

`TREG_API_KEY` was not in this agent's environment (injected secrets were the DataImpulse and Cloudflare credentials only; the Treg MCP connection was down), so a multi-day `searchAnalytics` query was not run. Prior-day and 7-day template figures below are the ones already in the attached gaps file.

**Navigational queries.** Bare brand and protocol-name queries are ignored as click gaps. On this day that removes the protocol-template misses that are the name itself: `pons` (28,603 impressions, 0 clicks), `vest markets` / `vestmarkets` / `vest market`, `papertrade`, `variational`, `stonkfun`, `perpl`, `justbet`, `defisaver`. `/protocol/pons` alone is 800 of the protocol template's 1,363 missed clicks. `/chain/base` (38.3 missed, position 2.20, CTR 1.03%) is treated the same way: the chain template's CTR is 9.49%, and `/chain/ethereum` and `/chain/solana` are about 5% at similar positions, so Base is an outlier on a shared title template, consistent with branded "base" queries. `/about` (10.8 missed at position 2.40) is the same kind of branded query.

**Live HTML.** Fetched 2026-10-14 with a browser user agent: the top pages by impressions, the hubs named in the brief, `/protocol/aave`, `/protocol/fees/aave`, `/protocol/tvl/aave`, `/protocol/unlocks/aave`, `/unlocks/aave`, one yield pool, `robots.txt`, `llms.txt`, and the sitemap index plus `sitemap/static.xml`, `sitemap/protocols.xml`, and `sitemap/chains.xml`.

**PageSpeed / CrUX.** Keyless `GET https://www.googleapis.com/pagespeedonline/v5/runPagespeed` returned HTTP 429. The same call through the DataImpulse rotating proxy (`gw.dataimpulse.com:823`) with `curl_cffi` Chrome impersonation returned the same 429. The body is a daily quota on the shared keyless consumer, not an IP block:

> Quota exceeded for quota metric 'Queries' and limit 'Queries per day' of service 'pagespeedonline.googleapis.com' for consumer 'project_number:583797351490'.

No lab scores and no URL-level or origin CrUX (LCP, INP, CLS) were collected. Decoded HTML sizes from the fetch are reported where they are large. They are not a substitute for field data.

**Repo.** Title, canonical, robots, and JSON-LD generation, sitemap construction, `robots.txt`, and `llms.txt`.
